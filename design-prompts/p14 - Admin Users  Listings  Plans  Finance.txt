Build a fully interactive, clickable HTML prototype for the HomzList Admin Panel (admin.homzlist.com) — the internal back-office of a premium real estate listing platform. This module: Users List, User Detail (deep-drill, all tabs), Listings Master, Plans Manager, Coupons, Grants & Trials, Finance, Payments (list + detail) — plus every side-panel, sheet, dialog and state — in ONE single HTML file with working click-navigation.

OUTPUT REQUIREMENTS
ONE self-contained HTML file (inline CSS + vanilla JS), no external libraries. Inline SVG outline icons (Lucide style, 1.5px stroke) — never emoji/cartoon icons.
Every screen = a section; JS click-navigation; browser back works (history.pushState); breadcrumbs navigate back; side-panels/sheets close on X / backdrop / Esc / browser back.
Deep-drill is the core principle of this packet: every entity name/ID anywhere must be clickable into its own side-panel, and panels stack (panel over panel) with a breadcrumb trail at the top of the stack (e.g. User → their Listing → its Leads → a Chat → the other participant's User panel). Back closes only the top panel.
Dev-toolbar (bottom-right, collapsible, minimal gray): jump to any screen/panel/state, toggle Light/Dark, toggle viewport (Desktop 1440 / Tablet 768 / Mobile 390), toggle admin role (Super Admin / Admin / Staff — must actually hide/disable restricted actions), toggle user state (active / suspended / deleted / trial / no-plan / multi-plan), toggle payment state (success / pending / failed / refunded / chargeback), toggle states (skeleton / empty / offline).
Responsive (admin = desktop-first): sidebar 240px (collapsible → 64px icon rail) + content max 1200px. At ≤767px: sidebar → bottom drawer (hamburger), tables → stacked cards, side-panels → full-screen sheets. Must be fully usable on a phone.
English only. Realistic Rajkot data (RK Properties, Nirav Shah, Meet Patel, Shreeji Builders, Priya Shah (admin); areas: Mavdi, University Road, Kalawad Road, 150 Feet Ring Road; society: Shree Residency, Green Valley Heights).
