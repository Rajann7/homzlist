Copy everything below → new Claude Design session → paste → generate → save.

Build a fully interactive, clickable HTML prototype for HomzList — a premium Instagram-style real estate listing PWA (website, mobile-first). This is the PROFILE module: Own Profile, Other User Profile, Edit Profile, Verification, Listing Stats, My Listings Manager — plus all sheets, dialogs and states — in ONE single HTML file with working click-navigation.
OUTPUT REQUIREMENTS

ONE self-contained HTML file (inline CSS + vanilla JS), no external libraries. Inline SVG outline icons (Lucide style, 1.5px stroke) — never emoji/cartoon icons.
Every screen = a section; JS click-navigation; browser back works (history.pushState); back arrows work; sheets close on X / backdrop tap / swipe-down / browser back.
Dev-toolbar (top-right, collapsible, minimal gray): jump to any screen/sheet/state, toggle Light/Dark, toggle Mobile/Tablet/Desktop, toggle role (Owner / Broker / Builder), toggle verification level (Phone / ID / RERA / revoked), toggle profile view (own / other / view-as-visitor / suspended / deleted), toggle listing states (Live / Pending / Changes requested / Rejected / Hidden / Archived / Sold / Rented), toggle states (skeleton / empty / offline).
Responsive: mobile-first 390px. At ≥768px the SAME design renders centered in a 470px column with #FAFAFA outside and hairline #DBDBDB column borders — no separate desktop layout (Instagram-web pattern).
English only. Realistic Rajkot data (RK Properties, Nirav Shah, Meet Patel, Shreeji Builders; areas: Mavdi, University Road, Kalawad Road, 150 Feet Ring Road, Raiya Road; society: Shree Residency, Green Valley Heights).
Production polish, Instagram-level. Not a wireframe.
