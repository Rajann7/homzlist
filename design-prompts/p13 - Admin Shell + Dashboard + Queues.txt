PACKET P13 — ADMIN: SHELL, DASHBOARD & ALL QUEUES (9 screens)

Copy everything below → new Claude Design session → paste → generate → save.

Build a fully interactive, clickable HTML prototype for the HomzList Admin Panel — the internal back-office for a premium real estate listing platform (admin.homzlist.com). This module: Admin Login, Dashboard, Listings Queue, Review Detail, Requirements Queue, Boost Queue, Verification Queue, Appeals Queue, Reports Queue — plus the global admin shell, all side-panels, sheets, dialogs and states — in ONE single HTML file with working click-navigation.

OUTPUT REQUIREMENTS
ONE self-contained HTML file (inline CSS + vanilla JS), no external libraries. Inline SVG outline icons (Lucide style, 1.5px stroke) — never emoji/cartoon icons.
Every screen = a section; JS click-navigation; browser back works (history.pushState); back/breadcrumbs navigate back; side-panels and sheets close on X / backdrop / Esc / browser back.
Dev-toolbar (bottom-right for admin, collapsible, minimal gray): jump to any screen/panel/state, toggle Light/Dark, toggle viewport (Desktop 1440 / Tablet 768 / Mobile 390), toggle admin role (Super Admin / Admin / Staff), toggle states (skeleton / empty / offline / locked-by-other / SLA-overdue).
Responsive rule (admin is different from the user app): desktop-first — sidebar 240px (collapsible to 64px icon rail) + content area max 1200px centered. At ≤767px: sidebar becomes a bottom drawer (hamburger in header), tables collapse into stacked cards, side-panels become full-screen. Everything must remain usable on a phone (approvals from phone at night is a real use case).
English only. Realistic Rajkot data (RK Properties, Nirav Shah, Meet Patel, Shreeji Builders; areas: Mavdi, University Road, Kalawad Road, 150 Feet Ring Road; society: Shree Residency, Green Valley Heights).
Production polish — a serious, dense, professional back-office. Not a wireframe.
