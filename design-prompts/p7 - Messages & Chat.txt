Build a fully interactive, clickable HTML prototype for HomzList — a premium Instagram-style real estate listing PWA (website, mobile-first). This is the MESSAGES & CHAT module: Messages Home (4 tabs), Message Requests, Chat Thread (full behaviour), Chat Details — plus all sheets, dialogs and states — in ONE single HTML file with working click-navigation.
OUTPUT REQUIREMENTS

ONE self-contained HTML file (inline CSS + vanilla JS), no external libraries. Inline SVG outline icons (Lucide style, 1.5px stroke) — never emoji/cartoon icons.
Every screen = a section; JS click-navigation; browser back works (history.pushState); back arrows work; sheets close on X / backdrop tap / swipe-down / browser back.
Dev-toolbar (top-right, collapsible, minimal gray): jump to any screen/sheet/state, toggle Light/Dark, toggle Mobile/Tablet/Desktop, toggle role (Buyer-sender / Poster-owner / Broker), toggle chat state (request-pending / accepted / number-requested / number-allowed / blocked / listing-archived / requirement-expired / offline-queue / declined-cooldown), toggle states (skeleton / empty / offline).
Responsive: mobile-first 390px. At ≥768px the SAME design renders centered in a 470px column with #FAFAFA outside and hairline #DBDBDB column borders — no separate desktop layout (Instagram-web pattern).
English only. Realistic Rajkot data (RK Properties, Nirav Shah, Meet Patel, Shreeji Builders; areas: Mavdi, University Road, Kalawad Road, 150 Feet Ring Road; society: Shree Residency).
Production polish, Instagram-level. Not a wireframe.
