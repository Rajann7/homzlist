PACKET P1 — AUTH & ENTRY (8 screens, interactive)
Copy everything below → paste in Claude Design → generate → save.

Build a fully interactive, clickable HTML prototype for HomzList — a premium Instagram-style real estate listing PWA (website, mobile-first). This is the AUTH & ENTRY module: 8 screens in ONE single HTML file with working click-navigation between them.
OUTPUT REQUIREMENTS

ONE self-contained HTML file (inline CSS + vanilla JS). No external libraries except Google Fonts if needed (prefer system fonts).
Every screen = a <section>; JS switches views on click. Browser back must work (use history.pushState). A visible back arrow where specified also navigates back.
Include a small floating dev-toolbar (top-right, collapsible) to jump to any screen and to toggle: Light/Dark mode, Mobile/Tablet/Desktop view, and error/loading states. This is for review only — style it minimal gray.
Responsive rule (critical): design is mobile-first at 390px. On tablet (≥768px) and desktop (≥1024px) the SAME design renders centered in a 470px column with #FAFAFA page background on either side and hairline #DBDBDB column borders — NO separate desktop layout (Instagram-web pattern).
English only. Real, realistic Indian (Rajkot) data — never lorem ipsum.
Production polish, not a wireframe. No cartoon icons, no emoji as icons — use inline SVG outline icons (Lucide style, 1.5px stroke).
