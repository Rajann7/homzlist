Build a fully interactive, clickable HTML prototype for HomzList — a premium Instagram-style real estate listing PWA (website, mobile-first). This module: Plans & Pricing, My Plan Dashboard, Payment History, Boost Purchase, Boost Status, Top-up Sheet, Notifications Screen — plus all sheets, dialogs and states — in ONE single HTML file with working click-navigation.
OUTPUT REQUIREMENTS

ONE self-contained HTML file (inline CSS + vanilla JS), no external libraries. Inline SVG outline icons (Lucide style, 1.5px stroke) — never emoji/cartoon icons.
Every screen = a section; JS click-navigation; browser back works (history.pushState); back arrows work; sheets close on X / backdrop tap / swipe-down / browser back.
Dev-toolbar (top-right, collapsible, minimal gray): jump to any screen/sheet/state, toggle Light/Dark, toggle Mobile/Tablet/Desktop, toggle role (Owner / Broker / Builder), toggle plan state (no plan / ₹999 active / ₹2,999 active / ₹9,999 active / multiple plans / expired / grace period / trial granted), toggle payment state (success / pending / failed / refunded), toggle boost state (none / pending approval / active / expired / rejected), toggle states (skeleton / empty / offline).
Responsive: mobile-first 390px. At ≥768px the SAME design renders centered in a 470px column with #FAFAFA outside and hairline #DBDBDB column borders — no separate desktop layout.
English only. Realistic Rajkot data. Indian currency formatting (₹999, ₹2,999, ₹85 Lakh, ₹1.2 Cr).
Production polish, Instagram-level. Not a wireframe.
