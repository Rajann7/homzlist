Build a fully interactive, clickable HTML prototype for HomzList — a premium Instagram-style real estate listing PWA. This is the FEED module: global shells + 3 feed variants + story viewer + all sheets, in ONE single HTML file with working click-navigation.
OUTPUT REQUIREMENTS

ONE self-contained HTML file (inline CSS + vanilla JS), no external libs. Inline SVG outline icons (Lucide style, 1.5px stroke) — never emoji/cartoon icons.
Each screen = a section; JS click-navigation + browser back (history.pushState). Sheets open/close with animation, backdrop tap, swipe-down, and back.
Dev-toolbar (top-right, collapsible, minimal gray): jump to any screen/sheet, toggle Light/Dark, toggle Mobile/Tablet/Desktop, toggle states (skeleton / empty / guest / offline), switch role (Owner-Broker view ↔ Builder view).
Responsive: mobile-first 390px; at ≥768px the same design renders centered in a 470px column with #FAFAFA outside and hairline #DBDBDB column borders. No separate desktop layout.
English only, realistic Rajkot property data (areas: Mavdi, Kalawad Road, University Road, 150 Feet Ring Road, Raiya Road; names: RK Properties, Shreeji Builders, Meet Patel, Nirav Shah). Use realistic property photos (interior/exterior) — never gray boxes except in skeleton.
Production polish. Instagram-level.

Touch targets: min 44×44 everywhere.
Motion: ease-out cubic-bezier(0.2,0,0,1). Sheet 300ms in / 250ms out (spring, drag-follow, dismiss if dragged >50%). Card press 100ms. Double-tap heart: scale 0→1.2→1.0 over 400ms then fade. Story segment 5s linear. Pull-to-refresh: resistance 0.5, trigger at 64px, spring back 300ms. Skeleton shimmer 1.2s loop. Toast up 200ms/hold 3s/down 200ms. New-listings pill drops in from -20px + fade 250ms. Header shrink 56→48px across first 80px of scroll (scroll-linked). Respect prefers-reduced-motion.
Image aspect ratios (locked): feed card photo 4:5 · story 9:16 · avatar 1:1 circle · suggested mini-card 1:1. Never stretch; cover-crop.
Card visual hierarchy (locked order): Photo → Price (largest text) → BHK/Area → Location → Poster. Nothing may outrank price except the photo.
