Decisions

  • The hub sheet becomes the page. On mobile the nine tiles live in a sheet behind the feed header's grid icon. On desktop the sidebar already carries them as links, so this page does the thing a sheet cannot: it puts the numbers in front of the tiles — Views, Leads, Live listings, Plan usage — and keeps the tiles as the way through.
  • Tiles ride carousels, one per group, keeping the app's own grouping and order.
  • The right rail carries what the seller checks daily: plan usage with the real counter, recent leads with the same "waiting on you" emphasis, and the boost state.
  • Builder variant. A builder's dashboard is their home (they have no public browsing), so the same page leads with projects instead of listings — the tiles themselves stay unfiltered because the server gates by entitlement, not role.
