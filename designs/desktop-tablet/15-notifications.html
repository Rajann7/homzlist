A · Notifications — Desktop 1440 (list + preferences rail)

Decisions

  • Preferences move beside the list. On mobile, notification settings are a separate screen behind the header's gear. On desktop they are five toggles — small enough to live in the rail, where a user who is annoyed by a notification can silence it in the same breath as reading it.
  • The groups stay Today · This week · Earlier, and each row keeps its subject thumbnail so a "new lead" line says which listing without opening it.
  • The bell in the header opens a 400px popover with the last few unread and a "See all" — the desktop convention, and it means the header bell is finally useful rather than a link to a page.
  • Dead-link state kept. The app's "This is no longer available" line stays, because a notification pointing at a deleted listing must say so rather than 404.
