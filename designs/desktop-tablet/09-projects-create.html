09 · Project create & insights
Builder-only, exactly as the app gates it: "New Project" appears because only a Builder can buy the ₹9,999 plan behind it, and project slots are their own counter. Unit types carry the app's own fields — Built-up area · Carpet area · Price from · Units available.

A · New project — Desktop 1440 (form + live preview)

Decisions

  • Unit types are the hard part, so desktop gives them room. On mobile each unit type is a separate sheet; here they stack as inline sub-forms with their four real fields side by side, and the preview shows the unit carousel a buyer will see. A builder entering six unit types on a phone is the single most painful flow in the app, and this is where desktop pays for itself.
  • RERA is a first-class block, not a field buried in "more": registration number, exemption toggle, and the document rows the project page renders under Approvals & documents.
  • Project slots, not listing slots. The counter line says "1 project slot left" and reads the builder's own counter — the app keeps these separate (migration 0065) and so does this.
  • Below 1200 the preview unpins to the bottom and the mobile action bar returns; the form itself is identical.

B · Project insights — Desktop 1440

Insights

  • The same three counts the app already computes — Views · Saves · Leads — plus the per-unit split, which is the question a builder actually asks ("which unit type is moving?").
  • The trend is a plain bar series, no library and no new colours: --accent and --accent-soft only. It is not a map and not a new metric — nothing here is invented data.
  • Listing insights (/listings/[id]/insights) use the same composition with one subject instead of unit types.
