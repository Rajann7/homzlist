What this file is for

  • It is the checklist for the port. If a component here matches the app after the change, every screen built from it matches too.
  • Sizes are the desktop ones: buttons 40 (32 small), inputs 44, radius 10–16, card radius 14–16, carousel gap 20 at desktop and 24 at 1600.
  • Every colour is a token. Dark mode is a token swap and nothing else — that is why the toggle changes the whole gallery without a single component-level override.
  • Tables appear only here and in Payments. Everywhere else the app uses cards or rows, per the owner's carousel rule.
